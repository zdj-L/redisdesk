# 连接工作区（本地实现说明）

## 交互
- 顶部全局导航只保留连接、诊断、审计、本机、设置。缓存目录与控制台属于具体连接。
- 连接表最后一列是「操作」，「目录」与「控制台」并排；也可双击行。表列拉伸满宽。打开后进入左右工作区：左侧常驻连接/DB/键目录树，右侧用标签打开键详情或控制台。工作区会异步建立真实连接，无须先测试。
- 一个连接复用一个可关闭工作区标签；切换键时左侧目录保持可见。右侧键详情与控制台为页内标签，绑定该连接与当前键。外层标签显示连接名称和 DB，提示包含地址。切换顶部全局选择不会改变已有工作区的目标。已连接但未选键时，右侧空态为「请选择键」，不是「未连接」。
- 连接详情默认折叠；表列可拖动调宽，完整内容有悬浮提示。短窗口打开工作区时聚焦子页面；“连接列表”返回管理但不丢失会话。
- 测试成功仅表示连通性验证通过，测试连接随后释放；工作区显示“已连接”才表示持有活动会话。
- 编辑或删除连接会关闭对应工作区，防止使用过期地址、凭据或保护策略。断开后可以重连。关闭标签、关闭应用会释放连接和临时索引；应用退出等待当前有限超时请求清理，但不阻塞界面线程。

## 目录和读取
- 按冒号分组，目录和键叶子分开；完整原始 bytes 是身份，名称相同的目录/键以及二进制键不会互相覆盖。为防异常超深键名，目录最多分 12 层，其余段作为叶子显示。
- MATCH 接受 Redis glob；输入 123 为精确匹配，cache:* 为前缀模式。
- 每次只 SCAN 一批（COUNT 500 为提示，不是 Redis 硬上限）。可以继续扫描，或遍历至游标为 0；支持取消和刷新。
- 去重键索引放在用户临时目录的 SQLite 文件，正常刷新、断开、关闭工作区时删除。界面一次最多展示 1000 个键，可翻页，不预取值。异常强制结束进程可能留下临时索引文件。
- 只有游标归零才显示本轮遍历结束；动态库不是快照。SCAN 的重复项会去重。
- 点击叶子才读取 TYPE、TTL 和当前页值。String 每块最多 64 KiB；List 每页 100；Hash/Set/Zset 使用游标（COUNT 100 为提示，保留实际游标，不截掉返回项再跳页）；Stream 按 ID 连续读取每页 100。
- 值按现有敏感规则遮罩。浏览只读；界面单页文本显示最多 256 KiB，超出明确提示截断。支持六种原生类型，不含模块 JSON。字符串若分块，在键操作栏显示「加载下一块」，不使用集合式上一页/下一页；哈希/列表/集合/有序集合/流在表格下方保留一套分页。重新点击键可回第一页。

## 控制台与安全
- 控制台为紧凑等宽命令区，局部「执行」按钮和 Ctrl+Enter，结果/错误/耗时写在输出中。底部可收起的操作日志记录本工作区实际发出的命令与结果摘要。
- 控制台真实调用 ConsoleService.execute，而不再只是 prepare 后显示成功。所有联网和审计操作在每连接串行后台执行器中运行。
- 预检、风险确认后，在发送前再次核验授权、保护档位、审计可写性；确认预览不产生重复 pending 审计。
- 写命令遵守原有角色、风险策略、键入连接名确认和 fail-closed 审计；生产保存强制只读，L4 条件和永久禁令不变。不会为了浏览开放 KEYS。
- 共享工作区拒绝 SELECT/AUTH/HELLO/RESET/事务切换和改变回复模式的 CLIENT 命令，以及 MONITOR，防止悄悄改变当前会话数据库、凭据、协议或阻塞共享连接。要操作另一个 DB，请另建连接。
- RESP2、不自动降低 TLS、DPAPI 凭据租约保持不变。界面不持有解密后的密码。未存储或丢失的凭据需要在编辑连接中重新填写并保存。
- 单机 direct + TCP 为当前可用拓扑，SSH/Cluster/Sentinel 沿用原有限制。

## 布局
- 左侧键树默认约占工作区宽度 34%，并限制在 280–420px；最小宽度 280px，水平分割条可拖。过长键名右侧省略并带提示，必要时可水平滚动。
- 右侧值区（字符串编辑器或集合表格）垂直拉伸占满剩余空间，最小高度 120px。操作日志默认收起；展开后高度为工作区垂直分割的约 22%，并限制在 80–120px，可再拖开。分割默认在用户拖动前随窗口缩放重算。
- 顶栏与工具栏使用紧凑边距，功能保留。控制台「执行」按钮最大宽度 96px，非全宽。

## 验证范围
`tests/test_connection_workspace.py` 使用隔离的本地 RESP 模拟服务和真实 redis-py 检验会话、SCAN/GET、六类型分页、确认/审计阻断、二进制键、临时索引清理、异步线程、标签绑定、紧凑布局和退出清理。测试中的 SET 只发送给模拟服务，不涉及用户真实 Redis。
