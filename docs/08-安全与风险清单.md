# 08 · 安全与风险清单（企业级）

> 文档集版本 v2.0（企业级安全） ｜ 2026-11-10 ｜ 关联：[02-架构](./02-架构与技术选型.md)（参数表 A.6~A.8）｜ [03-连接与凭据](./03-连接与凭据.md) ｜ [05-控制台](./05-命令控制台.md) ｜ [07-UI](./07-UI设计规范.md)
> 本篇是安全设计主体：身份与授权、凭据、传输、数据保护、审计不可篡改、交付完整性、合规映射、风险登记。

## 1. 定位与边界声明

**本工具是什么**：一个受本地账号与角色约束的 Windows 桌面 Redis 排查客户端。它保证"人在工具里做的事被最小化授权、被记录、被校验"，并默认拒绝高风险路径。

**本工具不是什么**（写进"关于"页与交付说明，避免被当成安全基础设施）：

| 不是 | 说明 |
| --- | --- |
| 不是 Redis 网关/代理 | 不集中管控凭据、不做统一鉴权、不做流量审计；任何人都可以绕开本工具直连 Redis |
| 不能替代网络隔离 | 生产 Redis 必须由安全组/ACL/跳板机限制来源；本工具不能阻止其它客户端 |
| 不能替代服务端 ACL | 客户端只读保护可被绕过（换工具即可）；服务端 ACL 才是强制边界 |
| 不能防止本机管理员 | 拥有本机管理员或同 Windows 账号的人可以读取数据文件、注入进程、dump 内存 |
| 不是 WORM 审计系统 | 哈希链只能"发现篡改"，不能"阻止删除"；合规留痕需外部集中收集 |

## 2. 威胁模型（STRIDE）

### 2.1 资产

| 资产 | 说明 | 敏感度 |
| --- | --- | --- |
| A1 Redis 凭据 | Redis 密码、SSH 口令/私钥口令、哨兵密码 | 极高 |
| A2 连接清单 | 主机、端口、拓扑、环境、备注（暴露内网结构） | 高 |
| A3 业务缓存数据 | key 名与值（可能含手机号、身份证、令牌） | 高 |
| A4 审计日志 | 操作留痕（含 key 名与命令） | 高 |
| A5 会话与角色 | 本地账号、角色、登录状态 | 高 |
| A6 安装包与依赖 | 可执行文件、第三方库 | 高 |

### 2.2 STRIDE 表

| 类别 | 威胁 | 攻击面 | 缓解 | 残余风险 |
| --- | --- | --- | --- | --- |
| **S** 仿冒 | 他人冒用同事账号操作生产 | 本地登录框 | 账号口令 + 失败锁定 + 空闲锁定 + 审计记账号 | 共享账号（A8） |
| S | 伪造更新包 | 手动更新 | 签名清单 + 拒绝未签名 + 拒绝降级 | 私钥泄露（R-34） |
| **T** 篡改 | 修改审计记录掩盖操作 | `redisdesk.db` | 哈希链 + 启动/手动校验 + 断链 fail-closed | 可整库删除（A2） |
| T | 篡改本地角色提升权限 | 数据库文件 | 文件 ACL 仅当前用户 + 完整性校验 | 本机管理员（A1） |
| **R** 抵赖 | 否认执行过写命令 | 审计 | 记录账号/角色/命令摘要/结果/耗时/哈希链 | 无第三方时间戳（A2） |
| **I** 信息泄漏 | 明文密码进日志/导出/崩溃转储 | 日志、导出包、崩溃文件 | DPAPI + 统一脱敏 + 禁止明文导出 + 崩溃日志不含参数 | 内存 dump（A3） |
| I | 敏感值被截屏/拍照 | 屏幕 | 默认遮罩 + 临时显示（限时/审计）+ 可选水印 | 拍照无法技术阻断（A4） |
| I | 明文连接被窃听 | `redis://` | 默认强制 TLS，明文需 Admin + 理由 + 审计 + 红色标识 | 服务端未开 TLS（A6） |
| **D** 拒绝服务 | `KEYS`/大 key 阻塞服务端 | 控制台、浏览 | L4 阻断 + 分页 + 扫描预算 + 超时 | 服务端自身容量 |
| D | 审计写失败导致无法作业 | 本地磁盘满/只读 | fail-closed（写命令拒绝）+ 明确提示 + 只读仍可用 | 可用性代价（见 §10） |
| **E** 提权 | Operator 执行 Admin 操作 | 控制台、UI 按钮 | 单一判定点 `AuthzService` + 服务端 ACL + 审计 | UI 绕过仅影响本人（同一进程） |

## 3. 身份与授权

### 3.1 本地账号体系

| 项 | 约定 |
| --- | --- |
| 账号来源 | 仅本地账号（`app_user` 表），无内置默认账号、无默认口令 |
| 角色 | 固定三角色 `viewer` / `operator` / `admin`，v1 不支持自定义角色（避免权限组合失控） |
| 首次启动 | 引导向导创建第一个 Admin（用户名 + 口令 + 确认口令）；同时生成一次性 **恢复码**（24 字符，仅展示一次，存储为 scrypt 哈希） |
| 口令策略 | 长度 ≥ `password_min_length=12`；至少 `password_complexity_classes=3` 类（大写/小写/数字/符号）；不得包含用户名；不得为内置弱口令表前 10000 条；不得与最近 `password_history_count=5` 次重复 |
| 口令存储 | `scrypt(N=32768, r=8, p=1, salt=16B, dklen=32)`，格式 `scrypt$32768$8$1$<salt_b64>$<hash_b64>`；比较用常量时间 |
| 口令有效期 | `password_max_age_days=90`，到期强制修改（可调 0=不过期，仅 Admin 可改） |
| 失败锁定 | 连续 `login_fail_lock_threshold=5` 次 → 锁定 `login_fail_lock_minutes=15`；24 小时内累计 `login_fail_daily_threshold=10` 次 → 锁定 `login_fail_daily_lock_minutes=60`，且需 Admin 解锁 |
| 账号禁用 | Admin 可禁用账号；禁用后立即失效（下次操作前校验会话） |
| 会话 | 登录后生成内存态 `SessionContext(user_id, role, login_at, last_active_at, unlocked)`；不写磁盘 |
| 空闲锁定 | `session_idle_lock_minutes=10`（5~30 可调）；锁定后需重新输入口令 |
| 绝对时长 | `session_absolute_hours=8`，超时强制重新登录（防止长期挂机） |
| 恢复 | 忘记 Admin 口令时用恢复码重置，需在同一 Windows 用户会话内操作；恢复码也遗失则需删除本地库重建（审计事件写入外部导出留档，见 A2） |
| SSO 扩展点 | 定义 `IdentityProvider` 协议（`authenticate(username, secret) -> Identity`、`capabilities()`）；v1 仅 `LocalIdentityProvider`。未来可接 Windows 域（SSPI/Negotiate）或 OIDC，但**本期不实现**，也不引入网络认证依赖 |

### 3.2 角色能力矩阵

行 = 能力，列 = 角色。`✓` = 允许，`△` = 允许但需附加动作（列内说明），`✗` = 拒绝（UI 禁用 + 发送前拦截）。

| 能力 | Viewer | Operator | Admin |
| --- | --- | --- | --- |
| 查看连接清单（名称/环境/拓扑/主机/标签） | ✓ | ✓ | ✓ |
| 连接"已授权给本角色"的连接 | ✓ | ✓ | ✓ |
| 浏览 key 列表与分页 | ✓ | ✓ | ✓ |
| 查看值（非敏感） | ✓ | ✓ | ✓ |
| 查看敏感值（默认遮罩） | ✓（遮罩） | ✓（遮罩） | ✓（遮罩） |
| 临时显示敏感值（60 s） | ✗ | △ 单次上限 10 次/分钟，审计 | △ 同左 + 可批量导出前复核 |
| 执行 L1 只读命令 | ✓ | ✓ | ✓ |
| 执行 L2 写命令 | ✗ | △ 确认框 | △ 确认框 |
| 执行 L3 高危命令 | ✗ | △ 二次确认 + 输入连接名 | △ 二次确认 + 输入连接名 |
| 执行 L4（dev/test 且已解锁） | ✗ | ✗ | △ 输入连接名 + 记录理由 |
| 修改 TTL / 删除单个 key | ✗ | ✓ | ✓ |
| 批量按模式删除 | ✗ | ✗ | △ 预估 + 限流 + 二次确认 |
| `CLIENT KILL` | ✗ | ✗ | △ 单条 + 展示目标 |
| 新建/编辑/删除连接 | ✗ | ✗ | ✓ |
| 给角色授予连接访问权 | ✗ | ✗ | ✓ |
| 标记"允许明文连接"（高风险例外） | ✗ | ✗ | △ 必须填写理由（≥10 字符），红色标识 + 审计 |
| 查看审计 | ✗ | ✗ | ✓ |
| 导出审计（CSV/JSONL） | ✗ | ✗ | ✓ |
| 导出脱敏数据（表格/值） | ✗ | ✓ | ✓ |
| 导出未脱敏数据 | ✗ | ✗ | △ 再次输入口令 + 记录理由 + 审计 |
| 管理本地账号与角色 | ✗ | ✗ | ✓ |
| 修改安全参数（锁定阈值、空闲时长、保留期） | ✗ | ✗ | ✓ |
| 执行审计链完整性校验 | ✗ | ✗ | ✓（启动时自动执行，结果所有人可见） |

判定原则：

1. **UI 置灰不等于权限**。所有判定在 `AuthzService.check(session, action, resource)` 中完成，位于 `RiskEngine` 之前，命令发送前必过；快捷键、历史回放、批量任务、诊断页动作走同一入口。
2. 角色不足时返回 E08（策略拒绝），文案写明"需要 Operator 角色"与"如何申请"，并写审计 `decision=deny, deny_reason=role`。
3. `admin` 不是"绕过策略"：L4 永久阻断项（`SHUTDOWN`/`DEBUG`/订阅阻塞命令）对 Admin 同样不可执行。

### 3.3 连接级授权

| 项 | 约定 |
| --- | --- |
| 授权模型 | `connection_grant(connection_id, role)`，行存在即该角色可连接；新建连接自动授予 `admin`，`operator`/`viewer` 需 Admin 显式授予 |
| 未授权连接的可见性 | **可见但不可连接**（选择"可见"方案）：列表显示灰色行 + 徽标"未授权"，点击提示"当前角色无该连接权限，请联系管理员"。理由：资产盘点需要知道"存在这个库"；完全隐藏会导致重复创建同一连接、且用户误以为数据丢失 |
| 例外 | Admin 可在设置中开启"未授权连接完全隐藏"（`hide_unauthorized_connections=false` 默认关），开启后需记录审计 |
| 切换连接 | 切换不影响会话解锁状态，但会清空上一连接的"临时显示"状态与值缓存 |
| 删除连接 | 同事务删除授权行与 `secret` 行；孤儿授权行启动时清理 |

### 3.4 命令级授权与判定顺序

统一管线（任何入口不得跳过）：

```
1 会话有效？        未登录/已锁定 → 拒绝（E08），要求认证
2 角色有该动作？    AuthzService → 拒绝（E08, reason=role）
3 连接已授权？      connection_grant → 拒绝（E08, reason=grant）
4 保护档位允许？    readonly/confirm/unrestricted → 拒绝（E08, reason=protection）
5 命令风险 L1~L4    RiskEngine（含参数规模） → L4 直接拒绝
6 审计可写？        写命令与 L3/L4 → 不可写则拒绝（fail-closed）
7 审计 pending      写入哈希链记录（同步）
8 执行              发送命令
9 审计 update       结果/耗时/影响估算
```

步骤 1~6 全部在 UI 线程之外或发送前完成，**不产生任何网络请求**。

## 4. 凭据保护

### 4.1 存储模式（连接级）

| 模式 | 默认 | 行为 | 适用 |
| --- | --- | --- | --- |
| `dpapi` | ✓ | 密码用 DPAPI（当前 Windows 用户 + 应用熵）加密后存本地库 | 日常 |
| `dpapi_master` | 可选 | DPAPI 密文再被主密码派生密钥（scrypt → AES-256-GCM）包裹；每次启动/解锁需输入主密码 | 高敏环境、共享电脑 |
| `not_stored` | 可选 | 不落盘，每次连接现输入；只保留用户名与主机 | 一次性排障、审计敏感 |

| 项 | 约定 |
| --- | --- |
| DPAPI 参数 | `CryptProtectData`，scope=当前用户，`CRYPTPROTECT_UI_FORBIDDEN`，熵=`redisdesk:v2:credential` |
| 主密码 | 长度 ≥ `master_password_min_length=12`；scrypt 派生 KEK；失败 `master_password_fail_threshold=5` 次锁定 `master_password_lock_minutes=15`；主密码不落盘、不写日志 |
| 内存明文 | 仅存在于 `SecretLease`（上下文管理器内），底层用 `bytearray`/`memoryview`，退出时清零；禁止把密码放入 `str` 常量、异常消息、repr、日志 |
| 生命周期 | 连接建立后立即释放租约；重连时重新取用；切换连接/锁屏/退出应用触发全量清零 |
| 禁止 | 明文写入配置文件、日志、审计、崩溃转储、命令历史、剪贴板（无"复制密码"按钮） |
| 换机/换用户 | DPAPI 解密失败 → E02，提示"凭据与 Windows 用户绑定，请重新输入"，不自动删除原密文 |

### 4.2 导出与备份

| 项 | 约定 |
| --- | --- |
| 明文导出 | **不存在任何路径**（无"包含密码"选项，无"导出为 JSON"直出） |
| 配置包 | 强制口令加密：`scrypt(N=32768, r=8, p=1, salt=16B)` + `AES-256-GCM(nonce=12B, tag=16B)`；AAD 绑定 `格式版本|导出时间|导出账号`；口令 ≥ `export_min_password=12`；连续 5 次错误锁定当前进程 15 分钟 |
| 内容 | 连接元数据 + 加密后的凭据 + 可调参数；不含审计、不含命令历史 |
| 日志提示 | 导出前红色警告："包内含可解密凭据，禁止放入代码仓库/IM/邮件"；导出事件写审计（不含包内容与口令） |
| 导入 | 校验格式版本、AAD、口令；导入的连接默认 `env=prod` 且只读，需 Admin 复核后修改 |

### 4.3 崩溃与日志

| 项 | 约定 |
| --- | --- |
| 日志脱敏 | 统一 `redact_argv()`；`AUTH`/`CONFIG SET requirepass`/`ACL SETUSER`/`MIGRATE AUTH` 参数替换 `***` |
| 崩溃日志 | 仅 traceback + 版本 + 时间；**不 dump 局部变量**（禁用 `faulthandler` 的 locals、关闭自定义 `sys.excepthook` 参数回显） |
| 系统级转储 | 说明限制：Windows WER 本地转储由系统策略控制，建议企业策略关闭本机 dump 或加密存储（见 A3） |
| 应用日志 | 不记录值内容、不记录完整 key 列表（仅数量与前 3 个示例，且示例走敏感规则遮罩） |

## 5. 传输安全

### 5.1 强制 TLS

| 项 | 默认 | 说明 |
| --- | --- | --- |
| TLS | **必需**（等价 `rediss://`） | 新建连接不勾 TLS 无法保存 |
| 协议版本 | `tls_version_min=TLSv1.2` | 允许升到 1.3；不允许 1.0/1.1 |
| 证书校验 | `tls_verify_hostname=true`（不可关闭） | 必须校验链与主机名；无"忽略证书错误"开关 |
| CA | 自签/私有 CA 必须显式指定 `ca_path` | 不读取系统信任库以外的隐式信任 |
| 客户端证书（mTLS） | 可选 `client_cert_path` + `client_key_path` | 私钥口令走 DPAPI；证书到期 < `tls_cert_expiry_warn_days=30` 时告警 |
| Sentinel | 独立 `sentinel_tls`（哨兵可能与非 TLS 数据面不同） | 哨兵连接默认也要求 TLS |
| Cluster | 所有节点继承连接 TLS | 不支持单节点降级；某节点不支持 TLS 则连接失败并提示 |
| 失败行为 | 握手失败/主机名不匹配/证书过期 → E01/E07，不重试不降级 | — |

### 5.2 明文例外（高风险）

| 项 | 约定 |
| --- | --- |
| 触发 | 用户取消 TLS 时必须选择"允许明文（不推荐）"，勾选风险确认并填写 `plaintext_reason`（≥ `plaintext_reason_min_chars=10` 字符） |
| 权限 | 仅 `admin`；`operator`/`viewer` 无该选项 |
| 标识 | 连接列表红色左边框 + 红色徽标"明文"，顶栏常驻红色提示 |
| 留痕 | 审计 `event=high_risk_plaintext, risk_level=L3, decision=allow`，记录理由与时间；连接每次连接都记 `event=connect_plaintext` |
| 复核 | Admin 可在审计页筛选"明文事件"；连接详情页显示"该连接为明文，创建人/时间/理由" |
| 不提供 | 批量把多条连接改为明文；导入包中的明文连接直接拒绝导入（需重新走例外流程） |

### 5.3 SSH 隧道加固

| 项 | 约定 |
| --- | --- |
| 认证方式 | 密钥优先（`auth_mode=key` 为推荐默认展示项）；口令认证需勾选 `ssh_password_auth=true`，标记"中风险"并写审计 |
| 主机指纹 | `strict` 默认；首次 `tofu` 需展示 SHA-256 指纹供人工确认并固定到 `known_hosts_redisdesk` |
| 指纹变更 | 直接拒绝（E07），**不提供一键忽略**；需用户手工核对并删除旧条目（文档给出路径） |
| 绑定地址 | 仅 `127.0.0.1`；端口默认随机 |
| 生命周期 | 随连接关闭释放；应用退出前统一 kill |
| 私钥 | 只读引用路径，复制到应用目录一律禁止；口令加密存储 |

## 6. 数据保护

### 6.1 敏感 key 规则

| 项 | 约定 |
| --- | --- |
| 存储 | `sensitive_rule` 表：`id, name, target(key_name/field_name/value), match_type(prefix/regex/contains), pattern, action(mask_full/mask_partial/hash), enabled, builtin, created_by, created_at` |
| 内置规则 | key 名：`*password*`、`*passwd*`、`*secret*`、`*token*`、`*credential*`、`*private*key*`；字段名：`password,passwd,pwd,token,secret,authorization,cookie,idcard,id_card,phone,mobile,email,bankcard`（内置规则可停用，不可删除） |
| 匹配范围 | 浏览列表的 key 名默认**不遮罩**（需可搜索），命中规则的**值**默认遮罩；`target=key_name` 规则可让 key 名也部分遮罩 |
| 遮罩样式 | `●●●●●● (已遮罩 · 42 字节)`；表格、抽屉、复制、导出统一生效 |
| 临时显示 | 点击"临时显示"→ 需 Operator+ → 显示 `sensitive_reveal_ttl_s=60` 秒后自动回遮罩；单次只显示一个字段；每分钟上限 `sensitive_reveal_max_per_minute=10` |
| 审计 | `event=reveal_sensitive`，记录 key 名（本身走遮罩规则）、字段名、账号、时间；不记录值 |
| 复制 | 复制遮罩值 → 提示"当前为遮罩内容"；复制明文需先"临时显示"，同样审计 |
| 规则误配风险 | 提供"规则测试器"（输入示例 key/field 预演命中结果），Admin 可试跑后再启用 |

### 6.2 导出与剪贴板

| 动作 | 默认 | 提升条件 |
| --- | --- | --- |
| 结果表格导出 CSV | 脱敏（敏感值替换为 `***`） | 未脱敏需 Admin + 再次输入口令 + 理由 ≥ 10 字符 + 审计 `event=export_unmasked` |
| 值复制 | 遮罩值可直接复制并提示 | 明文复制需先临时显示（审计） |
| 批量导出集合 | 不提供（见 04 §6.3） | — |
| 审计导出 | Admin，CSV/JSONL | — |
| 剪贴板 | 复制后 Toast 提示"已复制，注意剪贴板内容"；应用退出不清空系统剪贴板（说明限制） | — |

### 6.3 会话锁定与屏幕防护

| 项 | 约定 |
| --- | --- |
| 空闲锁定 | `session_idle_lock_minutes=10`，锁定后遮罩整个窗口，需口令解锁 |

| 锁屏联动 | 监听 Windows 会话锁屏（`WTSRegisterSessionNotification`）；不可用时降级为"仅空闲计时"，并在设置页说明 |

## 7. 审计与不可篡改

### 7.1 记录范围

| 事件 | 记录 | 备注 |
| --- | --- | --- |
| 登录成功/失败/锁定/解锁 | 是 | `event=auth_*`，记录用户名与失败原因（不含口令） |
| 账号/角色变更 | 是 | `event=user_change`，旧值→新值 |
| 连接授权变更 | 是 | `event=grant_change` |
| 敏感值临时显示 | 是 | `event=reveal_sensitive` |
| `L2` 写命令 | 是 | 允许/确认/错误/超时/取消 |
| `L3`/`L4` 尝试（含拒绝） | 是 | `decision=deny` 必须写原因 |
| 只读档/角色拒绝 | 是 | `reason=protection/role/grant` |
| 连接建立/断开（含明文） | 是 | 明文单独 `event=connect_plaintext` |
| 环境/保护档位/`allow_l4` 变更 | 是 | `profile_change` |
| 批量删除任务 | 是 | 模式、预估、实际、失败、耗时 |
| 配置包导入/导出 | 是 | 不记录包内容与口令 |
| 审计完整性校验结果 | 是 | `event=audit_integrity`，含校验行数与结果 |
| L1 只读命令 | 否 | 仅 DEBUG 日志（默认关） |

### 7.2 表结构（含哈希链）

```sql
CREATE TABLE audit_log (
    seq            INTEGER PRIMARY KEY AUTOINCREMENT,  -- 链序号，单调递增
    ts             TEXT    NOT NULL,   -- 本地时间 ISO8601（含毫秒）
    actor_user_id  TEXT    NOT NULL,
    actor_username TEXT    NOT NULL,
    actor_role     TEXT    NOT NULL,   -- viewer/operator/admin
    client_host    TEXT    NOT NULL,   -- 本机名
    client_ip      TEXT,               -- 本机 IPv4/IPv6（尽力采集）
    session_id     TEXT    NOT NULL,
    connection_id  TEXT,
    connection_name TEXT,
    env            TEXT,               -- prod/test/dev
    host           TEXT,               -- Redis 主机（不含密码）
    port           INTEGER,
    event          TEXT    NOT NULL,   -- command/connect/disconnect/auth_*/reveal_sensitive/...
    command_name   TEXT,
    argv_masked    TEXT,               -- 脱敏文本，≤ 200 字符
    argv_digest    TEXT,               -- argv 原文 SHA-256 前 16 位
    risk_level     TEXT,               -- L1~L4
    decision       TEXT    NOT NULL,   -- allow/confirm/deny
    deny_reason    TEXT,
    result         TEXT,               -- ok/err/blocked/cancelled/timeout/pending
    duration_ms    INTEGER,
    impact_estimate TEXT,              -- 如 "3 keys" / "≈ 12.4 MB"
    error_code     TEXT,
    hash_algo      TEXT    NOT NULL DEFAULT 'SHA-256',
    prev_hash      TEXT    NOT NULL,   -- 上一条 record_hash（首条为 64 个 0）
    record_hash    TEXT    NOT NULL
);
CREATE INDEX idx_audit_ts ON audit_log(ts);
CREATE INDEX idx_audit_user ON audit_log(actor_username, ts);
CREATE INDEX idx_audit_conn ON audit_log(connection_id, ts);
CREATE INDEX idx_audit_event ON audit_log(event, ts);

CREATE TABLE audit_chain_state (
    id            INTEGER PRIMARY KEY CHECK (id = 1),
    last_seq      INTEGER NOT NULL,
    last_hash     TEXT    NOT NULL,
    broken_at_seq INTEGER,          -- 非空表示检测到断链
    broken_detected_at TEXT,
    updated_at    TEXT    NOT NULL
);
```

### 7.3 哈希链算法

```
canonical = JSON(record 除 record_hash 外全部字段, 键按字典序, 紧凑分隔符, UTF-8, 时间归一化)
record_hash = SHA256( canonical_bytes || prev_hash_bytes )           # 64 位小写十六进制
genesis: prev_hash = "0" * 64                                         # 第 1 条
```

| 约束 | 内容 |
| --- | --- |
| 单写者 | 单实例互斥量 `Global\RedisDesk` 保证只有一个进程写链；写入串行化（同一事务内取 `audit_chain_state` 并更新） |
| 原子性 | `INSERT audit_log` + `UPDATE audit_chain_state` 在同一 SQLite 事务内；失败整体回滚 |
| 防重放 | `seq` 自增 + `prev_hash` 必须等于链状态 `last_hash`，否则写入失败（视为并发/篡改，拒绝） |
| 算法固定 | `hash_algo=SHA-256`；升级算法需新增字段并整链重算（不在 v1 实现） |
| 记录更新 | 结果回填（pending → ok/err）**不修改原哈希**：回填写一条新的 `event=command_result` 记录引用原 `seq`，保证链只追加 |

> 说明：结果回填采用"追加结果记录"而不是 UPDATE，是为了让链保持纯追加、可校验。原命令记录的 `result` 保留 `pending`，通过 `event=command_result` + `impact_estimate` 关联。

### 7.4 完整性校验

| 项 | 约定 |
| --- | --- |
| 自动校验 | 启动时 `audit_integrity_check_on_start=true`：从最近 500 条向前抽验 + 校验链状态与末条一致 |
| 全量校验 | Admin 手动触发，逐条重算（上限 `audit_integrity_full_check_max_rows=200000`），显示进度与耗时 |
| 断链处理 | 检测到断链 → ① 状态栏红色常驻横幅"审计链完整性异常（seq=1234）"；② **禁止所有写命令与 L3/L4 执行**（fail-closed）；③ 允许只读浏览与审计查看；④ 写入 `event=audit_integrity` 记录（新链从当前末条继续，标记 `broken_at_seq`）；⑤ 提供"导出异常区间"供离线取证；⑥ 只有 Admin 在确认后输入理由才能"确认已知晓并继续"（记录审计），且该状态不自动消失 |
| 校验工具 | 设置页"审计完整性"卡片：显示链长度、末哈希、最近校验时间、[立即全量校验]、[导出校验报告] |

### 7.5 写入失败行为（fail-closed）

| 场景 | 行为 | 理由 |
| --- | --- | --- |
| 写命令 / L3 / L4 的 pending 写失败 | **拒绝执行**，返回 E11，提示"审计不可写，已拒绝执行" | 记不下来就不做 |
| 执行后结果回填失败 | 命令已执行，写 `audit_update_failed` 到日志与状态栏红色提示，并阻止后续写命令直至恢复 | 已发生的事实无法回滚，只能止损 |
| L1 只读命令审计不需要 | 不受影响 | 保证可排障 |
| 连接事件写失败 | 拒绝建立连接（含只读连接） | 连接本身即敏感行为 |
| 数据库整体不可用 | 应用进入"只读降级模式"：可浏览已缓存连接？否——直接阻止连接，提示修复 | 避免无审计作业 |

### 7.6 保留、归档与导出

| 项 | 约定 |
| --- | --- |
| 保留 | `audit_retention_days=180`；行数上限 `audit_max_rows=200000`；启动与每日 03:00 清理过期数据（删除最旧） |
| 清理留痕 | 每次清理写一条 `event=audit_retention_purge`（含删除条数与区间），该记录不参与被删区间计算 |
| 归档 | 可选 `audit_archive_enabled=false`：清理前导出 `audit-YYYYMM.csv.gz` 到 `%LOCALAPPDATA%\RedisDesk\audit_archive\`（不含明文，本身也含脱敏后的命令） |
| 导出格式 | CSV（UTF-8 BOM）或 JSONL（一行一条，含 `record_hash`/`prev_hash` 便于外部复验）；Admin 专属 |
| 只读权限 | 审计页对 Operator/Viewer 不可见；Admin 内部分"查看"与"导出"两个动作，均审计 |
| 删除 | UI 不提供单条删除；不提供"清空审计"；仅按保留期自动清理 |

## 10. 强制项 vs 可用性代价（含例外路径与留痕）

## 11. 风险清单

### 11.1 R-01 ~ R-23（v1 沿用，v2 补充说明）

| 编号 | 风险 | 触发条件 | 后果 | 防护（v2 强化） | 观测信号 | 严重度 |
| --- | --- | --- | --- | --- | --- | --- |
| R-01 | `KEYS` 阻塞大实例 | 控制台输入 `KEYS *` | 单线程阻塞数秒~数十秒 | `KEYS` 归 L4；生产无解锁路径；仅 dev/test 且 Admin 可解锁 | `commandstats` 出现 `keys`；延迟尖峰 | 严重 |
| R-02 | 集合全量读取拖垮服务 | `HGETALL`/`SMEMBERS`/`LRANGE 0 -1` | O(N) 阻塞、内存暴涨 | 值查看器只分页；控制台超大区间判 L3 | 响应耗时、`omem` | 严重 |
| R-03 | `FLUSHALL/FLUSHDB` 误清库 | 误输、粘贴、历史回放 | 全库丢失 | L4；生产永久阻断；dev/test 也需 Admin + 输入连接名 + 理由 | 审计 `decision`、`INFO keyspace` | 严重 |
| R-04 | 批量删除误伤 | 模式过宽、测试连接指向生产 | 大面积删除 | 仅 Admin；单批 ≤ 500、总量 ≤ 10000；限流 + 二次确认 | 审计计数 | 严重 |
| R-05 | 写命令超时重试致重复 | 网络抖动 | 计数翻倍、消息重复 | 禁止写命令自动重试 | 审计同命令短时重复 | 高 |
| R-06 | `CLIENT KILL` 误伤 | 误选、批量清理 | 业务请求失败 | L3 + Admin 专属 + 单条 + 禁杀自身 | 审计目标 ID | 高 |
| R-07 | `CONFIG SET` 连锁故障 | 改淘汰策略/密码 | 命中率暴跌、全员断连 | L3 + 输入连接名 + 审计 | 审计、`evicted_keys` | 高 |
| R-08 | `SCRIPT FLUSH` 致脚本失败 | 清空脚本缓存 | 接口大面积 `NOSCRIPT` | L3 + 明确后果 | 服务端 `NOSCRIPT` | 高 |
| R-09 | `MONITOR`/订阅压垮服务 | 长时间采集 | CPU/带宽持续升高 | `MONITOR` 仅非生产 + 10 s 自动停；订阅永久阻断 | `CLIENT LIST` 中 `O` 标志 | 高 |
| R-10 | 凭据泄漏 | 明文写配置/日志/导出 | 未授权访问 | DPAPI（+主密码可选）+ 统一脱敏 + 禁止明文导出 | 日志抽检、审计 | 严重 |
| R-11 | 审计/日志泄漏业务数据 | 记录完整 value | 合规风险 | 审计仅摘要 ≤200 字符 + 敏感规则遮罩 | 抽检 `argv_masked` | 中 |
| R-12 | SSH 隧道被借用 | 绑 `0.0.0.0`、长开 | 绕过网络隔离 | 仅 `127.0.0.1` + 随会话释放 + 随机端口 | 端口抽查 | 高 |
| R-13 | Sentinel 切换写旧主 | 切换瞬间 | 数据丢失/双写 | 取连接校验 `ROLE`；`READONLY` 强制重发现；写不重试 | `READONLY` 错误 | 高 |
| R-14 | 集群跨槽部分成功 | 多 key 跨槽 | 结果不一致 | CRC16 分组执行；跨槽事务拒绝 | 结果"跨 N 槽" | 中 |
| R-15 | 大 key 内存统计阻塞 | `MEMORY USAGE SAMPLES 0` | 延迟抖动 | 单 key 前提示；批量强制 `SAMPLES 5` | 命令耗时 | 中 |
| R-16 | 恶意内容致界面异常 | 0x00、超长、HTML 片段 | 渲染卡死、误点 | 纯文本渲染、HEX、截断、懒加载 | 崩溃日志 | 中 |
| R-17 | 本地库被同机读取 | 目录权限过宽 | 连接清单/历史泄漏 | 文件 ACL 收紧 + DPAPI + 主密码模式 | ACL 检查 | 中 |
| R-18 | 审计被删除 | 清理数据库/重装 | 无法追溯 | 哈希链 + 不可 UI 删除 + 归档 + 外部留存建议 | 链长度、`audit_integrity` | 中 |
| R-19 | 依赖供应链 | 篡改的第三方库 | 任意代码执行 | 固定版本 + 哈希锁 + 离线构建 + 签名 | 构建日志 | 中 |
| R-20 | 共享电脑会话残留 | 离开未锁屏 | 他人操作 | 10 分钟空闲锁定 + 锁屏联动 + 关闭清零 | `auth_lock` | 中 |
| R-21 | 环境标错（生产标测试） | 建连时选错 | 误开写权限 | 建连强制确认 + 生产 host 提示 + 只读默认 | `profile_change` | 高 |
| R-22 | TLS 中间人 | 忽略证书/信任被植入 | 凭据被窃 | 强制校验、无忽略开关；建议企业证书策略 | 握手失败日志 | 高 |
| R-23 | 剪贴板泄漏 | 复制值后粘贴到外部 | 数据外泄 | 复制提示 + 敏感值需临时显示才可复制明文 | 无（不可观测） | 中 |

### 11.2 R-24 ~ R-41（v2 新增·身份与数据保护）

| 编号 | 风险 | 触发条件 | 后果 | 防护 | 观测信号 | 严重度 |
| --- | --- | --- | --- | --- | --- | --- |
| R-24 | 弱口令/共享账号 | 多人用同一 Admin；口令简单 | 无法归责、越权 | 口令策略 + 90 天有效期 + 失败锁定 + 审计记账号；建议一人一号 | `auth_login` 同一账号多来源 | 高 |
| R-25 | 本地角色被篡改提权 | 直接改 `app_user.role` | Operator 变 Admin | 文件 ACL（仅当前用户 + Administrators）+ 启动校验用户表哈希；角色变更审计 | `user_change`、启动校验告警 | 中 |
| R-26 | 明文连接例外被滥用 | 图方便全部标"允许明文" | 凭据被窃听 | 仅 Admin + 理由 + 红色标识 + 每次连接审计 + 审计页筛选复核 | `high_risk_plaintext` 频次 | 高 |
| R-27 | TLS 信任库被植入 | 本机安装恶意根证书 | 中间人成功 | 无法完全防；建议企业证书策略 + 可选证书指纹固定（`tls_pin_sha256`，P2） | 证书指纹变化告警 | 中 |
| R-28 | SSH 口令爆破 | 跳板机暴露 + 弱口令 | 主机被入侵 | 密钥优先 + 口令认证标记中风险 + 失败锁定建议在服务端 | `connect` 中 `auth_mode=password` | 中 |
| R-29 | 敏感规则漏配 | 业务字段名不含内置关键词 | 敏感值明文展示 | 规则测试器 + 定期复核 + 支持自定义正则；默认对 `value` 类规则取保守匹配 | 规则命中率统计 | 中 |
| R-30 | 临时显示被滥用 | 反复点开截图 | 敏感数据外泄 | 60 s 自动回遮罩 + 每分钟 10 次上限 + 逐次审计 + 可选水印 | `reveal_sensitive` 频次 | 中 |
| R-31 | 审计断链/篡改 | 手工改库、进程崩溃 | 追溯失效 | 哈希链 + 启动校验 + 断链 fail-closed + 导出取证 | `audit_integrity`、`broken_at_seq` | 高 |
| R-32 | 审计写失败导致业务中断 | 磁盘满/库锁 | 无法执行写命令 | fail-closed 是有意设计；提供磁盘空间告警与修复指引；只读浏览不受影响 | 状态栏、`E11` | 中 |
| R-33 | 用户名枚举/暴力破解 | 登录框提示差异 | 账号被发现 | 统一提示"用户名或口令错误"；失败计数按用户名 + 本机；锁定与退避（第 4 次起 1 s 延迟） | `auth_login_failed` | 中 |
| R-34 | 安装包/更新包被替换 | 分发渠道不可信 | 任意代码执行 | Authenticode + 签名清单 + 私钥 HSM + 双人复核 + 拒绝未签名 | 签名校验日志 | 严重 |
| R-35 | 降级攻击 | 用旧版本漏洞包替换 | 绕过新安全策略 | 拒绝降级（版本必须更高）+ 最低兼容版本校验 | `update_verify` | 高 |
| R-36 | 数据目录权限过宽 | 默认继承 `Users` | 同机他人读取 | 首次运行收紧 DACL（移除继承） | `icacls` 检查 | 中 |
| R-37 | 水印被误当防护 | 认为开了水印就安全 | 防护缺失 | 设置页与文档明确"仅威慑与溯源，不阻断截屏" | 文档评审 | 低 |
| R-38 | 无 SSO 导致账号分散 | 每人本地建号 | 离职账号残留 | 提供"账号清单导出"供定期复核；预留 `IdentityProvider` 扩展点 | 账号清单 | 中 |

| R-40 | 审计/数据导出外泄 | 导出 CSV 后转发 | 数据泄漏 | 导出需权限 + 默认脱敏 + 未脱敏需二次认证 + 文件头标注密级 + 建议 DLP | `export_*` 事件 | 高 |
| R-41 | 恢复码保管不当 | 写在便签/共享文档 | Admin 被重置 | 恢复码仅展示一次 + 存储为哈希 + 使用即失效并审计 | `auth_recovery_used` | 中 |

## 13. 残余风险（诚实列出）

| 编号 | 残余风险 | 为什么无法消除 |
| --- | --- | --- |
| A1 | 本机管理员可读取/修改一切 | 管理员可读 DPAPI 密文所在库、改角色字段、注入进程；应用层无法对抗同机管理员 |
| A2 | 审计非 WORM，可被整库删除 | 本地 SQLite 无防删能力；哈希链只能发现被改，不能阻止删除；合规需外部集中收集（如 SIEM） |
| A3 | 无法防内存 dump | Python 对象与 GC 会留下明文副本；`bytearray` 清零只能缩短窗口；专业工具可 dump 进程 |
| A4 | 无法阻止拍照/专业截屏 | 水印仅威慑与溯源；DPAPI 之外没有硬件级隔离 |
| A5 | 同 Windows 账号即同身份 | DPAPI 用户级保护；账号共享时行为无法区分到人（R-24） |
| A6 | 服务端未开 TLS 时只能靠例外 | 工具不能替服务端开 TLS；明文例外是妥协方案 |
| A7 | 采样估算不精确 | 大 key / 批量内存为估算（±20%） |
| A8 | `SCAN` 非快照 | 浏览期间数据变化导致"看得到打不开" |
| A9 | 无多因素认证 | 单机离线工具，未接入 MFA；建议通过 Windows Hello/智能卡在系统层补充 |
| A10 | 取消不保证服务端停止 | 断连只停止等待，命令可能已执行完 |
| A11 | 依赖系统时间 | 审计时间使用本机时间，可被改；无第三方时间戳 |
| A12 | 无集中管理 | 每人一份本地库；策略无法统一下发（需 GPO 或后续服务端化） |
