# 07 · UI 设计规范

> 文档集版本 v2.0（企业级安全） ｜ 2026-11-10 ｜ 设计系统来源：`dbsync/app/ui/theme.py`（只读参考，不修改）｜ 页面功能见 03~06 ｜ 安全约束见 [08](./08-安全与风险清单.md)

---

## 1. 设计原则

| 编号 | 原则 |
| --- | --- |
| U1 | **状态可见**：任何长操作都有进度、耗时、取消；任何危险操作都有醒目徽标 |
| U2 | **颜色不是唯一通道**：风险/状态同时用图标文字 + 颜色（色弱可辨） |
| U3 | **浅色默认、深色可切换**：所有颜色来自语义 token，界面代码零字面色值 |
| U4 | **信息密度优先**：这是一个排障工具，表格行高 30 px、页面边距 20 px，不做大留白营销风 |
| U5 | **不隐藏限制**：集群、只读、大 key、扫描预算等约束必须在界面上可见，不能只在文档里 |
| U6 | **复用 dbsync 设计体系**：token 命名、QSS 模板方式、Card/Badge/DataTable/EmptyState 结构保持一致，降低维护成本 |
| U7 | **身份始终可见**：顶栏常驻当前账号与角色；锁定状态覆盖全窗口，不允许"看不见就继续操作" |
| U8 | **危险状态必须刺眼**：明文连接、审计断链、审计不可写、未授权连接四类状态用红色（`danger`）常驻标识，不可关闭 |
| U9 | **遮罩是默认态**：敏感值先显示遮罩，明文是"用户主动请求 + 有倒计时 + 有记录"的临时状态 |

## 3. 信息架构与导航

| 顺序 | 页面 | 导航文案 | 主要职责 | 依赖连接 |
| --- | --- | --- | --- | --- |
| 1 | `connections.py` | 连接 | 连接列表、编辑、测试、导入导出 | 否 |
| 2 | `browser.py` | 浏览 | Key 扫描 + 值查看器 | 是 |
| 3 | `console.py` | 控制台 | 命令执行与历史 | 是 |
| 4 | `diagnostics.py` | 诊断 | 概览 / 慢查询 / 客户端 / 内存 / INFO | 是 |
| 5 | `audit.py` | 审计 | 本地审计查询与导出（仅 Admin 可导出） | 否 |
| 6 | `users.py` | 账号 | 本地账号、角色、连接授权（仅 Admin 可见） | 否 |
| 7 | `settings.py` | 设置 | 主题、参数、日志级别、关于 | 否 |

规则：

- **登录前只显示登录窗口**，不渲染主窗口；首次启动进入向导，未完成不得进入主界面。
- 未连接时，"浏览/控制台/诊断"导航项置灰，点击提示"请先选择连接"，并跳转连接页。
- 导航项按角色过滤：`viewer` / `operator` 不显示"账号"页；`viewer` 不显示"审计"页（审计查询仅 Operator 起）。
- 顶栏连接切换器是一个下拉：显示 `名称 + 环境徽标 + 保护徽标`；**未授权连接显示为灰色 + "未授权"徽标且不可选**（08 §3.3）；切换连接时清空当前页数据（浏览页保留过滤条件），并清除所有临时显示状态。
- 导航项使用 `QPushButton#nav`（左侧 3 px 高亮条），与 dbsync 一致；图标 18 px。
- 页面切换用 `QStackedWidget`，不重建页面（保留各自状态）。

## 4. 语义色 token

与 dbsync `theme.py` 的 `TOKENS_LIGHT` / `TOKENS_DARK` 完全同源（复制实现，不建立依赖）。QSS 不支持 CSS 变量，采用 `string.Template` 注入：

```python
_QSS_TEMPLATE = string.Template("... QWidget { color: $text_primary; ... }")
def make_qss(tokens: dict[str, str]) -> str:
    return _QSS_TEMPLATE.substitute(tokens)   # 缺 token 直接报错，禁止静默漏色
```

## 5. 字体与排版

| 用途 | 字体 | 字号 | 字重 |
| --- | --- | --- | --- |
| 页面标题（`pageTitle`） | Microsoft YaHei UI | 20 px | 700 |
| 品牌名 | Microsoft YaHei UI | 17 px | 700 |
| 卡片标题（`sectionTitle`） | Microsoft YaHei UI | 14 px | 600 |
| 正文 / 表格 | Microsoft YaHei UI | 13 px | 400 |
| 说明（`hint`）/ 表头 | Microsoft YaHei UI | 12 px | 400 / 600 |
| 徽标 | Microsoft YaHei UI | 11 px | 600 |
| Key、值、命令、日志 | Consolas / Courier New | 12 px | 400 |

- 所有等宽内容用 `mono` token 上色，不允许用字面色值。
- 数字列（TTL、大小、耗时、score）右对齐；字节数用 `KB/MB/GB`（1024 进制）并保留 1 位小数。
- 时间统一本地时区，格式 `yyyy-MM-dd HH:mm:ss`；耗时 < 1 ms 显示 `0.x ms`。

## 6. 组件规格

### 6.1 徽标（Badge）

| 类型 | 文案 | 前景/底色 token | 说明 |
| --- | --- | --- | --- |
| 只读安全 `L1` | `√ 只读` | `success` / `success_soft` | 只读命令 |
| 写入 `L2` | `! 写入` | `warn` / `warn_soft` | 单 key 写操作 |
| 高危 `L3` | `× 高危` | `danger` / `danger_soft` | 需输入连接名 |
| 阻断 `L4` | `× 阻断` | `danger` / `danger_soft` + 1 px `danger` 描边 | 默认不可执行 |
| 环境-生产 | `生产` | `danger` / `danger_soft` | 顶栏常驻 |
| 环境-测试 | `测试` | `warn` / `warn_soft` | 顶栏常驻 |
| 环境-开发 | `开发` | `text_secondary` / `surface_alt` | 顶栏常驻 |
| 保护-只读 | `只读` | `text_secondary` / `surface_alt` | 顶栏常驻 |
| 保护-确认 | `确认制` | `accent` / `accent_soft` | 顶栏常驻 |
| 保护-无限制 | `无限制` | `warn` / `warn_soft` | 仅 dev/test |
| 连接状态 | `已连接` / `连接中断` / `只读副本` | success / danger / warn | 配合 8 px 状态点 |
| 角色 | `查看者` / `操作员` / `管理员` | `text_secondary` / `accent` / `accent` | 顶栏常驻，仅文字不带色块差异 |
| 未授权连接 | `未授权` | `text_secondary` / `surface_alt` | 卡片与切换器灰显，不可点 |
| 明文连接 | `明文` | `danger` / `danger_soft` + 1 px `danger` 描边 | 卡片、顶栏、控制台三处常驻 |
| 审计异常 | `审计不可写` / `审计断链` | `danger` / `danger_soft` + 描边 | 状态栏 + 顶部红色横幅 |
| 锁定 | `已锁定` | `warn` / `warn_soft` | 仅锁屏遮罩内显示 |

徽标样式复用 dbsync `badge_qss(tokens, fg, bg, strong=False)`：`padding 2px 7px; radius 4px; 11px/600`。所有徽标**必须带文字或符号**，不允许只靠颜色块。

### 6.2 表格（DataTable）

| 项 | 规格 |
| --- | --- |
| 基类 | `QTableView` + 自定义 `QAbstractTableModel`（Key 列表用虚拟模型；小结果可用 `QTableWidget`） |
| 斑马纹 | `alternatingRowColors=True`（`table_alt`） |
| 网格线 | 关闭（`setShowGrid(False)`），只用行间距与对齐区分 |
| 表头 | `surface_alt` 底、12 px/600、左对齐（数字列右对齐）、无排序箭头除非可排序 |
| 行高 | 30 px；`padding 5px 8px` |
| 省略 | 单元格超长用 `ElideDelegate` 省略 + tooltip 显示全文 |
| 选中 | 整行选择（`SelectRows`）；多选仅批量删除场景开启 |
| 空状态 | 表格区域替换为 `EmptyState`（图标 + 标题 + 说明 + 可选按钮） |
| 加载态 | 表头保留，表体显示 3 行骨架行（`surface_alt` 闪烁 200 ms 周期） |
| 错误态 | 表体显示错误卡片（`inlineDanger`）：错误码 + 原因 + 建议 + "重试" |

### 6.3 抽屉（Drawer）

| 项 | 规格 |
| --- | --- |
| 用途 | 值详情、命令历史、INFO 原文、审计详情 |
| 宽度 | 480 px；遮罩 `rgba(0,0,0,0.2)` |
| 结构 | 标题栏（标题 + 关闭）→ 元信息（key/类型/大小/耗时）→ 内容区（可滚动）→ 底部操作（复制/HEX 切换） |
| 关闭 | `Esc`、点遮罩、关闭按钮；不因切换主题丢失 |
| 禁止 | 抽屉内提供任何写操作按钮（写操作只走控制台） |

### 6.4 风险确认框（ConfirmDialog）

| 区域 | 规格 |
| --- | --- |
| 尺寸 | 520 × 自适应（最大 640） |
| 标题 | 徽标 + `即将执行 <命令名>` |
| 主体 | 命令等宽展示（脱敏）→ 后果段（`warn`/`danger` 底色）→ 影响估算 → 输入确认 |
| 输入 | 占位符 `请输入连接名：订单/生产/只读`；不匹配时按钮禁用 + 红字提示 |
| 按钮 | 左"取消"（默认焦点，`ghost`）、右"确认执行"（`danger` 或 `primary`） |
| 键盘 | `Esc` 取消；`Enter` 仅在输入正确且焦点在输入框时提交 |
| 记录 | 取消也写入审计（`decision=deny`，`reason=user_cancelled`） |

### 6.5 其他组件

| 组件 | 规格 |
| --- | --- |
| 进度条（带取消） | `QProgressBar` 高 16 px + 右侧"取消"；未知总量时用不确定模式 + 文字"已扫描 12,000" |

| 分页器 | `第 N 页 · 每页 100` + 上一页/下一页；游标模式显示"游标 0x1f3a" |
| 状态点 | 8 px 圆点（`StatusDot`），颜色随连接状态 |
| 分节卡片 | 诊断页每个分节一张 `Card`，标题右侧放"复制命令"图标按钮 |
| 信息表 | 两列键值表（键 12 px `text_secondary`，值 12 px 等宽），无斑马纹 |
| 分隔线 | 1 px `border`，上下间距 12 px |
| 遮罩单元格 | 固定 `••••••`（6 点，不随明文长度变化）；右侧"眼睛"图标按钮（`viewer` 隐藏）；tooltip"已遮罩 · 命中敏感规则" |
| 失效操作 | 角色/授权不足的按钮：不透明度 40%、`cursor=forbidden`、tooltip 写明"需要 X 角色/该连接未授权"，不弹窗打断 |

### 6.6 敏感值临时显示组件

| 项 | 规格 |
| --- | --- |
| 触发 | 点击遮罩右侧"临时显示"图标；每次只对当前单元格/字段生效 |
| 倒计时 | 明文右侧显示 `59s` 递减徽标（`warn` 底），到 0 立即回遮罩并从内存清除明文 |
| 次数限制 | 超过 `sensitive_reveal_max_per_minute=10` 时按钮禁用，tooltip"操作过于频繁，请稍后再试" |
| 角色限制 | `viewer` 不渲染按钮，仅显示遮罩与锁图标 |
| 复制 | 仅明文状态下"复制"得到明文；遮罩状态复制得到遮罩文本 |
| 失效清理 | 切换连接、切换 key、锁定、重登、关闭页面时立即回遮罩 |
| 记录 | 每次显示写审计 `event=reveal_sensitive`，界面不额外提示（避免打断），审计页可见 |

### 6.7 登录 / 首次启动 / 锁屏

| 界面 | 结构 |
| --- | --- |
| 登录 | 标题"RedisDesk"→ 账号下拉（本机已有账号）→ 口令输入（`EchoMode.Password` + 显示切换）→ "登录"主按钮 → 左下"忘记密码（使用恢复码）"→ 右下版本号；错误内联并显示剩余次数（"口令错误，还可尝试 3 次"） |
| 锁定（失败达阈值） | 登录按钮禁用并显示倒计时"已锁定，14:32 后可重试"；不提供"管理员解锁"捷径 |
| 首次启动向导 | 第 1 步：管理员账号名 + 口令 + 确认口令（实时显示强度与规则命中）；第 2 步：**一次性展示 24 位恢复码** + "已抄写"勾选 + 复制（剪贴板 60 s 后提示清除）；第 3 步：可选创建首个连接或进入主界面 |
| 恢复码重置 | 输入恢复码 → 设置新口令 → 提示"恢复码已使用，请生成新的恢复码"；全程写审计 |
| 锁屏遮罩 | 显示当前账号、角色、锁定原因（"空闲 10 分钟自动锁定"/"手动锁定"/"系统锁屏联动"）；输入口令解锁；"切换账号"回登录窗口 |
| 断链模态 | 启动即发现断链：顶部红色横幅 + 首次进入时模态说明（不可忽略）——只读应急模式、被禁操作、恢复步骤 |

### 7.6 设置页

分节卡片：外观（主题三选一）、浏览默认值（`scan_count`、`key_page_size`、`value_page_size`、是否显示 TTL）、控制台（默认超时、历史条数）、诊断（慢查询条数、自动刷新间隔）、**安全**（会话空闲时长展示、审计状态与校验入口、敏感规则说明、水印开关）、日志（级别、打开日志目录）、关于（版本、构建号、依赖版本、**签名状态**）。

安全分节中所有影响策略的参数**只读展示**（`password_min_length`、`login_fail_lock_threshold`、`session_idle_lock_minutes`、`tls_version_min` 等），不提供界面修改；如需调整，仅 Admin 通过配置文件并重启（配置变更写审计）。

## 8. 状态与交互规范

| 状态 | 表现 | 文案要求 |
| --- | --- | --- |
| 加载中 | 骨架行 + 顶部细进度条；> 1 s 显示已用时间 | "正在读取 500 个 key…" |
| 空（未开始） | `EmptyState`，图标 `search` | "输入名称模式或直接开始扫描" |
| 空（无结果） | `EmptyState`，图标 `inbox` | "没有匹配的 key，试试放宽模式或类型" |
| 无权限（只读） | 按钮禁用 + 徽标"只读" + tooltip 说明原因 | "当前连接为只读保护，写命令已被禁用" |
| 错误 | 内联错误条（`inlineDanger`）+ 错误码 + 建议 | "E03 读超时（5s）：可降低 scan_count 或提高超时" |
| 预算耗尽 | 黄色条 + 三个操作按钮 | "已扫描 2,000,000 个 key，命中 8,921" |
| 断开 | 顶栏红点 + 页面顶部黄条 | "连接已中断，[重连]" |
| 未授权连接 | 卡片/切换器灰显 + "未授权"徽标；按钮禁用 | "当前账号未被授权访问该连接，请联系管理员分配" |
| 明文连接 | 卡片 + 顶栏常驻 `明文` 红色徽标；控制台输入框下方提示条 | "该连接未使用 TLS，凭据与数据以明文传输（例外已记录）" |
| 会话锁定 | 全窗口遮罩 + 解锁卡片 | "已锁定：空闲 10 分钟。请输入口令继续" |
| 审计不可写 | 顶部红色横幅 + 状态栏红点；写操作按钮禁用 | "审计不可用：写操作已暂停，只读功能正常" |
| 审计断链 | 顶部红色横幅 + 模态说明 + 只读应急提示 | "审计链校验失败：已进入只读应急模式，请联系管理员处理" |

### 8.1 键盘快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Enter` | 控制台执行 |
| `↑` / `↓`（输入框内） | 上/下一条历史 |
| `Ctrl+F` | 聚焦当前页搜索/模式输入 |
| `F5` | 刷新当前页（浏览页=重新扫描；诊断页=重新拉取） |
| `Esc` | 关闭抽屉/对话框；浏览页清空右侧面板 |
| `Ctrl+D` | 切换浅色/深色 |
| `Ctrl+L` | 立即锁定（不清空连接，但隐藏所有内容） |
| `Ctrl+1..7` | 切换导航页（按角色过滤后仍按固定序号映射） |

快捷键不得绕过风险策略：`F5` 重新扫描不触发写操作；`Ctrl+L` 锁定后所有快捷键失效，仅保留解锁输入；历史回放类快捷键同样走 05 §3.0 判定。

### 8.2 文案规范

| 规则 | 示例 |
| --- | --- |
| 错误三段式 | `发生了什么` + `为什么` + `怎么办`，如"连接超时（5 秒）。目标 10.0.0.11:6379 未响应。请检查网络或调大超时。" |
| 按钮动词化 | 用"删除 key"而不是"确定"；危险按钮不用"是/否" |
| 数字带单位 | `12,400 个 key`、`3.2 KB`、`240 ms` |
| 不承诺精确 | 估算值一律带"约/估算"前缀 |
| 不用缩写歧义 | `TTL`、`SCAN`、`slot` 保留英文（业界通用），其余中文 |

## 9. 可访问性与主题实现

| 项 | 要求 |
| --- | --- |
| 对比度 | 正文与背景 ≥ 4.5:1；徽标文字与底色 ≥ 3:1 |
| 双通道 | 风险/状态必须"颜色 + 符号文字"；图表类（进度）附数值文本 |
| 焦点 | 可交互控件有 1 px `accent` 焦点描边；键盘 Tab 顺序符合视觉顺序 |
| 缩放 | 125%/150% 下无文字截断；表格列宽可拖拽 |
| 动效 | 仅抽屉滑入（200 ms）与 Toast 淡入；不做循环动画；尊重系统"减少动画"设置（若可读取则禁用） |
| 主题切换 | `apply_tokens(tokens)` 遍历页面控件重新上色，不重建控件；切换后立即写 `ui-settings.json` |
| 图标 | 内置 SVG（`icons.py`），单色 + token 上色，18/20/32 px 三档；不使用 emoji |
