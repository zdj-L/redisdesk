## 1. 定位与交互

命令控制台是**唯一的写入口**（值查看器不提供编辑）。设计目标是"能查到、能验证、但不能手滑"。

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ 目标连接：[订单/生产/只读 ▾] 角色：Operator  保护：只读  超时：[10] s [执行] │
├──────────────────────────────────────────────────────────────────────────────┤
│ > GET user:1001                                                              │
│                                                                              │
├──────────────────────────────────────────────────────────────────────────────┤
│ 风险徽标（仅 L2+ 显示）  [√ 只读] / [! 写入] / [× 高危] / [× 阻断]           │
├──────────────────────────────────────────────────────────────────────────────┤
│ 结果表格：# │ 类型 │ 长度 │ 值 │ 耗时(ms) │ 状态                              │
│        1 │ bulk │ 42   │ {"name":"张三"} │ 0.8 │ 命中                          │
├──────────────────────────────────────────────────────────────────────────────┤
│ [结果] [原始回复]   复制值   导出 CSV（仅当前结果）   历史记录 ▾              │
└──────────────────────────────────────────────────────────────────────────────┘
```

| 交互 | 规则 |
| --- | --- |
| 执行 | `Ctrl+Enter`；工具栏按钮同效；执行中按钮变"取消" |
| 输入框 | 多行 `QPlainTextEdit`，等宽字体；行高 20 px；支持语法高亮命令名（仅首词） |
| 多行语义 | 换行等价于空格（便于粘贴长命令）；真实换行值用三引号块 `"""..."""` |
| 一次一条 | 不拆分 `;`、不支持管道/重定向/变量；含未转义 `;` 直接拒绝并提示"一次只执行一条命令" |
| 连接上下文 | 顶部显示连接名 + 环境 + 保护档位；切换连接时清空结果但保留历史（历史按连接过滤） |
| 执行前置 | 先本地解析 → **授权（会话/角色/连接授权/档位）** → 风险判定 → 审计预写 → 通过后才发往服务端；任何一步失败都不产生网络请求（见 §3.0） |

## 2. 风险模型

### 2.1 四级定义

| 等级 | 名称 | 含义 | 默认处理 |
| --- | --- | --- | --- |
| `L1` | 只读安全 | 不改数据、不阻塞、不影响其它客户端 | 直接执行 |
| `L2` | 写入 | 修改单个 key 或少量数据 | 弹确认（`unrestricted` 档不弹，`readonly` 档拒绝） |
| `L3` | 高危 | 影响面广、不可撤销、可能阻塞服务端 | 二次确认 + **输入连接名** + 审计 |
| `L4` | 阻断 | 清库、停机、调试、阻塞连接等 | 默认拒绝；仅 dev/test 且开启 `allow_l4` 可解锁（仍需输入连接名）；生产永久阻断 |

### 2.2 命令清单

| 命令（含同族） | 等级 | 触发条件 | 后果 | 防护 |
| --- | --- | --- | --- | --- |
| `GET/MGET/STRLEN/GETRANGE/EXISTS/TYPE/TTL/PTTL/SCAN/OBJECT/DUMP` | L1 | 任意 | 无 | 直接执行 |
| `HGET/HMGET/HSCAN/HLEN/HEXISTS` | L1 | 任意 | 无 | 直接执行（`HKEYS/HVALS` 见 L3 规则） |
| `LRANGE/LINDEX/LLEN` | L1 | `LRANGE` 区间长度 ≤ 500 且 `stop` 不为 `-1` | 大区间 O(N) | 超限拒绝 |
| `SCARD/SSCAN/SISMEMBER` | L1 | 任意（`SMEMBERS` 见 L3） | — | — |
| `ZCARD/ZSCORE/ZSCAN/ZRANGE/ZCOUNT` | L1 | `ZRANGE` 区间长度 ≤ 500 | — | 超限拒绝 |
| `XLEN/XRANGE/XREVRANGE/XINFO/XPENDING` | L1 | `XRANGE` 必须带 `COUNT ≤ 500` | 无 `COUNT` 会全量返回 | 强制补 `COUNT` 或拒绝 |
| `INFO/CONFIG GET/COMMAND/DBSIZE/ROLE/TIME/PING/ECHO/LASTSAVE` | L1 | 任意 | — | — |
| `CLIENT LIST/CLIENT INFO/CLIENT GETNAME/CLIENT ID` | L1 | 任意 | — | — |
| `SLOWLOG GET/SLOWLOG LEN` | L1 | `count ≤ 512` | — | 超限截断 |
| `MEMORY USAGE/MEMORY STATS/MEMORY DOCTOR` | L1 | `MEMORY USAGE` 仅单 key | 大 key 上 O(N) | 提示耗时 |
| `CLUSTER INFO/NODES/SLOTS/KEYSLOT/COUNTKEYSINSLOT/GETKEYSINSLOT` | L1 | 任意 | — | — |
| `SET/SETNX/SETEX/PSETEX/GETSET/GETDEL/APPEND/SETRANGE` | L2 | 任意 | 覆盖/追加数据 | 确认；审计 |
| `INCR/DECR/INCRBY/DECRBY/HINCRBY/ZINCRBY/ZADD` | L2 | 任意 | 数值变更 | 确认；审计 |
| `HSET/HSETNX/HDEL/LPUSH/RPUSH/LPOP/RPOP/LSET/LTRIM/LINSERT` | L2 | 任意 | 集合变更 | 确认；审计 |
| `SADD/SREM/SPOP/ZREM/EXPIRE/PEXPIRE/EXPIREAT/PERSIST` | L2 | 任意 | 集合/过期变更 | 确认；审计 |
| `RENAME/RENAMENX/COPY` | L2 | 目标 key 已存在时提示覆盖 | 覆盖目标 | 确认文案显式说明"将覆盖目标 key" |
| `XADD/XDEL/XTRIM/XACK/XGROUP CREATE|SETID|DESTROY` | L2 | 任意 | Stream 变更 | 确认；审计 |
| `PUBLISH/SPUBLISH` | L2 | 任意 | 触发订阅方行为 | 确认；只读档阻断 |
| `SCRIPT LOAD/SCRIPT EXISTS/SCRIPT KILL` | L2 | `SCRIPT KILL` 仅能杀只读脚本 | 加载脚本到缓存 | 确认 |
| `SLOWLOG RESET/LATENCY RESET/CLIENT SETNAME` | L2 | 任意 | 丢失历史诊断数据 | 确认（`CLIENT SETNAME` 除外，直接允许） |
| `DEL/UNLINK`（1 个 key） | L2 | 单 key | 删除数据 | 确认；审计 |
| `DEL/UNLINK`（≥ 2 个 key 或批量任务） | L3 | key 数 > 50 或来自批量删除流程 | 批量不可逆 | 二次确认 + 输入连接名 + 限流（见 06 §5） |
| `EVAL/EVALSHA/FCALL/FCALL_RO` | L3 | 任意 | 任意逻辑，可能写、可能阻塞 | 二次确认 + 输入连接名；只读档一律阻断 |
| `MONITOR` | L3 | 仅 `env != prod` 且 `allow_l4` | 持续输出全部命令，显著增加 CPU/带宽 | 最长采集 `monitor_max_duration_s=10`，到时自动停止 |
| `CONFIG SET/CONFIG REWRITE` | L3 | 任意 | 改运行时参数（最大内存/淘汰策略/密码） | 二次确认 + 输入连接名；审计 |
| `SCRIPT FLUSH` | L3 | 任意 | 清空脚本缓存，业务 `EVALSHA` 立即失败 | 二次确认 + 输入连接名 |
| `CLIENT KILL/CLIENT NO-EVICT/CLIENT UNPAUSE` | L3 | 任意 | 断开他人连接 | 二次确认 + 输入连接名；先展示目标客户端信息 |
| `SAVE/BGSAVE/BGREWRITEAOF` | L3 | 任意 | 触发持久化，可能 IO 抖动 | 二次确认 + 输入连接名 |
| `RESTORE` | L3 | 任意 | 覆盖写入序列化数据 | 二次确认 + 输入连接名 |
| `MIGRATE` | L3 | 任意 | 跨实例迁移并删除源 key | 二次确认 + 输入连接名 |
| `MEMORY PURGE` | L3 | 任意 | 强制释放内存，抖动 | 二次确认 |
| `FLUSHALL/FLUSHDB` | L4（受控） | 仅 `env=dev/test` 且 `allow_l4=true` | 清空全库，不可恢复 | 输入连接名 + 二次确认；生产永久阻断 |
| `SWAPDB` | L4（受控） | 同上 | 两个 DB 数据互换，业务读错库 | 同上 |
| `REPLICAOF/SLAVEOF` | L4（受控） | 同上 | 改变主从关系，可能造成数据丢失/脑裂 | 同上 |
| `ACL SETUSER/ACL DELUSER/ACL SETUSER ...` | L4（受控） | 同上 | 改权限，可能导致锁死或越权 | 同上 |
| `FAILOVER/CLUSTER RESET/MEET/FORGET/ADDSLOTS/DELSLOTS/SETSLOT/REPLICATE/SET-CONFIG-EPOCH` | L4（受控） | 同上 | 集群拓扑变更，极高风险 | 同上 |
| `SHUTDOWN` | L4（永久） | 无解锁入口 | 停服 | 控制台不提供执行路径；即使粘贴也拒绝 |
| `DEBUG *`（`SLEEP`/`OBJECT`/`JMAP`/`SEGFAULT`…） | L4（永久） | 无解锁入口 | 阻塞/崩溃/泄漏 | 永久阻断 |
| `SUBSCRIBE/PSUBSCRIBE/SSUBSCRIBE/UNSUBSCRIBE` | L4（永久） | 无解锁入口 | 占用连接、消息无限流 | 永久阻断，提示"本工具不提供订阅客户端" |
| `BLPOP/BRPOP/BLMOVE/BRPOPLPUSH/WAIT/XREAD BLOCK` | L4（永久） | 无解锁入口 | 阻塞连接直到超时 | 永久阻断，提示改用非阻塞命令 |
| `KEYS` | L4（受控，仅 dev/test） | 仅 `env != prod` 且 `allow_l4` | O(N) 阻塞，大实例上秒级卡死 | 提示"请用 SCAN"，需输入连接名；**生产连接无解锁路径** |
| `SMEMBERS/HKEYS/HVALS/ZRANGE 0 -1` | L3 | 元素数 > 10,000 | O(N) 单次全量 | 先 `HLEN/SCARD/ZCARD` 判断，超限要求改用分页命令 |
| `SORT` | L3 | 任意 | 大集合 CPU 飙升 | 二次确认 + 输入连接名 |

> 清单未覆盖的新命令按"未知命令"处理：默认 L3（需确认），并要求用户先在测试环境验证；`readonly` 档直接拒绝。

### 2.3 风险判定实现

```python
def assess(argv: list[str], profile: ConnectionProfile,
           runtime: RuntimeFacts) -> RiskAssessment:
    name = argv[0].upper()
    rule = RISK_CATALOG.match(name, argv, runtime)   # 先按名称，再按参数/规模细化
    if profile.env == "prod" and rule.level in (L3, L4) and rule.irreversible:
        return RiskAssessment(L4, reason="生产环境禁止不可逆操作", ...)
    ...
```

判定必须考虑**参数规模**（如 `DEL k1 k2 ... k100` 因 key 数升级为 L3），因此规则接口签名是 `(name, argv, runtime)`，不能只看命令名。

### 2.4 角色 × 风险等级矩阵

| 角色 \ 等级 | L1 | L2 | L3 | L4（受控） | L4（永久） |
| --- | --- | --- | --- | --- | --- |
| `viewer` | 允许 | **拒绝** | **拒绝** | **拒绝** | **拒绝** |
| `operator` | 允许 | 确认 | 二次确认 + 输入连接名 | **拒绝** | **拒绝** |
| `admin` | 允许 | 确认 | 二次确认 + 输入连接名 | 仅 `env != prod` + 输入连接名 + 理由 ≥ `plaintext_reason_min_chars`（10）字符 | **拒绝** |

补充：

- 本矩阵与 §3.1"档位 × 等级"是**与**关系：两者都允许才执行。例如 Admin 在 `readonly` 连接上仍不能执行 L2。
- L4 永久阻断名单（`SHUTDOWN`、`DEBUG *`、订阅类、阻塞类）**对 Admin 同样不可执行**；Admin 不是"绕过策略"。
- 未知命令默认 L3，`viewer` 一律拒绝；`readonly` 档一律拒绝。
- 角色不足返回 E08，文案写明"需要 Operator 角色"与申请方式；`deny_reason=role`。
- 完整能力矩阵（含导出、审计、账号管理等非命令能力）见 [08 §3.2](./08-安全与风险清单.md)；本条只约束命令执行。

## 3. 拦截与确认

### 3.0 判定顺序（发送前唯一入口）

任何能产生 Redis 请求的路径——`Ctrl+Enter`、工具栏执行、历史回放、快捷键重放、批量任务、诊断页"复制命令后执行"——都必须经过同一个 `AuthzService.check(session, action, resource)` → `RiskEngine.assess(argv, profile, runtime)`，顺序固定：

| 步骤 | 判定 | 不通过时 |
| --- | --- | --- |
| 1 | 会话有效且未锁定 | E08 拒绝，跳转登录/解锁 |
| 2 | 角色具备该动作（§2.4） | E08，`deny_reason=role` |
| 3 | 连接已通过 `connection_grant` 授权 | E08，`deny_reason=grant` |
| 4 | 保护档位允许该等级（§3.1） | E08，`deny_reason=protection` |
| 5 | 风险等级判定（含参数规模） | L4 直接拒绝，`deny_reason=risk` |
| 6 | 审计可写（写命令与 L3/L4） | E13，`deny_reason=audit_unavailable` |
| 7 | 审计 pending 记录落盘成功 | E13（同上） |
| 8 | 发送并把结果回填 |
| 9 | 追加审计结果事件（不改原记录） |

- 步骤 1~7 全部不产生网络请求。
- UI 置灰只是体验层；即使通过快捷键、脚本注入或历史回放绕过 UI，也会在 2~5 步被拒。
- 判定逻辑只允许实现在 `core/authz.py` 与 `core/policy.py`（依赖规则 R7），页面代码不得自带判断，也不得缓存"上次已允许"的结论。
- 完整 9 步管线与各步错误码见 [08 §3.4](./08-安全与风险清单.md)。

### 3.1 保护档位 × 风险等级矩阵

| 档位 | L1 | L2 | L3 | L4（受控） | L4（永久） |
| --- | --- | --- | --- | --- | --- |
| `readonly` | 允许 | **拒绝** | **拒绝** | **拒绝** | **拒绝** |
| `confirm` | 允许 | 确认 | 二次确认 + 输入连接名 | 拒绝（若 `allow_l4` 则走 L4 流程） | **拒绝** |
| `unrestricted` | 允许 | 直接执行 | 二次确认 + 输入连接名 | 允许（需 `allow_l4`，`env != prod`） | **拒绝** |

补充：

- `typed_confirm_required`（默认开）：关闭时 L2/L3 只需点"确认"，L4 仍必须输入连接名。**`env=prod` 时该开关不可关闭**。
- 只读档下，`EVAL/EVALSHA/FCALL` 与 `PUBLISH` 一律拒绝（脚本与消息都可能产生写副作用）。
- 被拒绝的命令**不产生任何网络请求**，只写审计 `decision=deny`。

### 3.2 确认框规格

| 区域 | 内容 |
| --- | --- |
| 标题 | `[! 需确认] 即将在「订单/生产/只读」执行 DEL`（徽标颜色按等级） |
| 命令 | 等宽字体展示解析后的 `argv`（敏感参数按 §6 脱敏），可展开"原始输入" |
| 后果 | 一句话说明（来自命令清单的"后果"列），L3/L4 追加不可逆提示 |
| 影响估算 | 批量命令显示"将删除 312 个 key（已扫描 500 个匹配）"；无法估算时显示"影响范围未知" |
| 输入 | L3/L4：`请输入连接名以确认`（精确匹配，含大小写与空格），输入框下方实时校验 |
| 按钮 | `[取消]`（默认焦点）/ `[确认执行]`（仅输入正确后可用） |
| 超时 | `confirm_dialog_timeout_s=0`（不自动关闭）；避免用户误触 Enter |

### 3.3 输入解析（`core/parser.py`）

| 规则 | 说明 |
| --- | --- |
| 分隔 | 空格/制表符/换行（换行视为空格） |
| 引号 | 双引号 `"..."`、单引号 `'...'`，内部空格保留 |
| 转义 | `\\`、`\"`、`\'`、`\n`、`\t`、`\r`、`\xNN`（十六进制字节） |
| 三引号 | `"""..."""` 保留真实换行，用于写入多行文本值 |
| 命令名 | 不区分大小写，发送前统一大写（参数保持原样） |
| 拒绝 | 未闭合引号、非法 `\x`、未转义 `;`、管道 `|`、重定向 `>`/`<`、`$VAR` |
| 解析失败 | 本地返回 E10 类提示，高亮出错位置（列号），不发送 |
| 空输入 | 不发送，状态栏提示 |

不使用 `shlex.split`：Windows 路径反斜杠与 `\xNN` 字节转义需要自定义规则，且必须可测试（`tests/test_parser.py`）。

## 4. 执行与结果渲染

### 4.1 执行管线

```
解析 → 授权与风险判定（§3.0 步骤 1~5）→ 审计预写（`decision=pending`，同步入哈希链）
     → 发送（worker 线程）→ 收到回复 → 结果规范化（含敏感遮罩）
     → 追加审计结果事件（`event=command_result`，引用原 `seq`）→ 渲染
```

| 情况 | 处理 |
| --- | --- |
| 服务端错误（`ERR/WRONGTYPE/OOM/READONLY`） | 保留原始错误文本，状态列标红；不重试（写命令尤其禁止重试） |
| 超时 | `console_timeout_s` 到点 → 取消 → 提示"已超时，服务端可能仍在执行"；审计记录 `timeout` |
| 跨槽（Cluster） | 多 key 命令按 CRC16 分组，逐槽执行后合并；结果顶部标注"跨 3 个槽，分 3 次执行，总耗时 4.2ms" |
| 跨槽事务 | `MULTI/EXEC/WATCH` 涉及多槽 → 直接拒绝（E05），提示"集群事务仅支持同槽（可用 hash tag）" |
| Key 不存在 | `nil` → 状态列显示"未命中"；`EXISTS` 返回 0 同样标"未命中" |

**审计只追加、不更新**：命令结果以新记录 `event=command_result` 追加，`ref_seq` 指向 pending 记录，避免 `UPDATE` 破坏哈希链（算法见 08 §7.3）。因此命令执行后审计表会出现成对记录（`command_attempt` → `command_result`），查询页默认折叠为一行展示。

### 4.2 结果表格

| 列 | 内容 |
| --- | --- |
| `#` | 序号（数组元素/多 key 结果逐行） |
| `类型` | `bulk` / `integer` / `array` / `nil` / `error` / `status` / `map`（RESP3 预留） |
| `长度` | bulk 字节数；array 元素数 |
| `值` | 预览 `value_preview_chars=200`；超长省略 + tooltip；二进制显示 `HEX · N 字节`；命中敏感规则时显示 `••••••`（可临时显示） |
| `耗时(ms)` | 单命令总耗时（集群分组时为各组耗时之和，组明细在 tooltip） |
| `状态` | `命中` / `未命中` / `成功` / `错误` / `截断` |

- 行数上限 `console_result_max_rows=10000`，文本上限 `console_result_max_bytes=5 MB`；超出显示"结果已截断，共 N 行"并提供"仅保留前 1000 行"的提示。
- 值详情抽屉：双击行查看完整值，支持复制与 HEX 切换。
- `原始回复` 页签：RESP 风格纯文本（`+OK`、`$42`、`*3`），只读展示，便于对照。
- 导出 CSV（P2）：只导出当前结果表格，文件名含连接名与时间戳，不含任何凭据；**导出默认脱敏**（`export_default_masked` 固定开），去脱敏需 Admin + 再次输入本地口令 + 理由 ≥10 字符，审计 `event=export_unmasked`。
- 敏感值遮罩：结果中的值、`key` 名、`field` 名命中 [08 §6.1](./08-安全与风险清单.md) 规则时默认遮罩；"临时显示"仅对当前选区生效，`sensitive_reveal_ttl_s=60` 秒后自动回遮罩，每分钟最多 `sensitive_reveal_max_per_minute=10` 次，每次写审计 `event=reveal_sensitive`（记录 key 名摘要，不记录值）。
- 切换连接、重新登录、空闲锁定后，结果区一律清空并清除所有临时显示状态；不继承上一连接的解锁。

### 4.3 审计不可写时（fail-closed）

| 情形 | 行为 |
| --- | --- |
| 审计库不可写（磁盘满/被独占/`PRAGMA integrity_check` 失败） | 写命令与 L3/L4 一律拒绝，返回 E13，提示"审计不可用，写操作已暂停"；只读命令可继续 |
| 只读命令在审计不可写期间执行 | 允许，但顶栏挂红色常驻横幅"审计不可写：N 条操作未留痕"，且不可关闭 |
| 发送后结果回填审计失败 | 结果照常展示但结果区标红，并在修复前禁止后续写命令 |
| 哈希链断链（`record_hash` 校验失败） | 进入只读应急模式：仅允许 L1，禁止导出、禁止修改安全参数；处理流程见 [08 §7.4](./08-安全与风险清单.md) |
| 修复后解除 | 仅 Admin 可执行完整性校验，成功才解除限制；解除动作本身写审计 `event=audit_recover` |

> 原则：**宁可少做一次写操作，也不留一次无记录的写操作**。只读操作不因审计故障被阻塞，避免"一个坏库让排障全停"。

### 4.4 命中/未命中的判定

| 命令 | 命中语义 |
| --- | --- |
| `GET/GETDEL/HGET/LINDEX/ZSCORE/XGET` | 非 `nil` = 命中，`nil` = 未命中 |
| `EXISTS/HEXISTS/SISMEMBER` | `1` = 命中，`0` = 未命中 |
| `MGET/HMGET` | 按元素统计"命中 2 / 3"，状态列显示汇总 |
| `TYPE` | 返回 `none` = 未命中 |
| 其它 | 状态列不显示命中，只显示成功/错误 |

## 5. 命令历史

| 项 | 约定 |
| --- | --- |
| 存储 | SQLite `console_history`：`id, connection_id, actor, raw(脱敏后), argv_digest, risk_level, decision, result, created_at` |
| 容量 | `console_history_max=1000` 条，按连接分别保留，超出按时间淘汰 |
| 浏览 | 输入框内 `↑/↓` 逐条替换；工具栏"历史"抽屉列表（时间、命令、等级、结果） |
| 搜索 | 抽屉内关键字过滤（对 `raw` 子串匹配） |
| 复用 / 回放 | 点击历史项填入输入框，或点"重放"直接执行；**重放必须重新走 §3.0 全流程**（角色/授权/档位/风险/审计），不复用上次判定结果，也不复用上次解锁状态；L3/L4 历史项带红色徽标 |
| 可见性 | 历史按"账号 + 连接"隔离：`viewer` 看不到 `admin` 执行过的写命令（`decision=allow` 且 `risk_level >= L2` 的记录不展示，只显示条数） |
| 删除 | 支持单条删除与"清空本连接历史"（需确认，属本地数据） |
| 脱敏 | 历史中的 `AUTH ...`、`CONFIG SET requirepass ...` 参数值保存为 `***`（与审计同规则） |
| 不记录 | 解析失败的输入（避免脏数据），但保留在输入框供修改 |

## 6. 脱敏规则（审计与历史共用）

| 命令模式 | 处理 |
| --- | --- |
| `AUTH <password>` / `AUTH <user> <password>` | 最后一个参数替换 `***` |
| `HELLO ... AUTH <user> <password>` | `AUTH` 后的密码替换 |
| `CONFIG SET requirepass|masterauth <value>` | 值替换 `***` |
| `CONFIG SET <任意> <含 password/secret/token 的参数名>` | 值替换 `***` |
| `ACL SETUSER <user> >password` | `>` 开头的口令参数替换 `***` |
| `MIGRATE ... AUTH <password>` / `AUTH2 <user> <password>` | 口令参数替换 |
| SSH/连接凭据 | 永不进入命令历史（不是 Redis 命令） |

实现方式：`infra/log.py` 与 `infra/audit.py` 共用同一个 `redact_argv(argv) -> list[str]`，禁止各自实现一份。值级遮罩（按 key 名/字段名/值内容命中）由 `core/redact.py` 提供，两者不合并：前者是"命令参数脱敏"，后者是"数据内容遮罩"。

命令**结果**同样脱敏：`GET token:*`、`HGET user:1 password`、`HGETALL` 类脚本返回的敏感字段默认打码；临时显示 60 秒并计审计（见 §4.2）。导出与剪贴板一律走 `export_default_masked` 路径，去脱敏需 Admin + 二次口令 + 理由，审计 `event=export_unmasked`。日志中只允许出现命令名与参数个数，不写入参数值（`AUTH` 例外：连命令名后的参数个数也不记）。

## 7. 取消与超时

| 场景 | 行为 |
| --- | --- |
| 用户点"取消" | 置 `CancellationToken`，worker 关闭当前 socket；界面显示"已取消（服务端可能已执行）" |
| 超时 | 同取消，错误码 E03；审计记录 `result=timeout` |
| 取消后状态核对 | 提供快捷按钮"用只读命令核对"（对 L2 写命令）：自动填入 `TYPE/EXISTS/TTL` 到输入框，不自动执行 |
| 禁止 | 不使用 `CLIENT KILL` 杀自己的连接来取消（会误伤；直接断 socket 更可控） |

## 8. 审计联动

| 事件 | 是否审计 | 字段要点 |
| --- | --- | --- |
| L1 执行成功 | 否 | 仅 DEBUG 日志 |
| L2 执行（任意结果） | 是 | `risk_level=L2, decision=allow/confirm, result=ok/err` |
| L3/L4 尝试（含被拒） | 是 | `decision=deny` 时 `result=blocked`，记录拒绝原因 |
| 取消/超时 | 是 | `result=cancelled/timeout` |
| 只读档拦截 | 是 | `decision=deny, reason="readonly protection"` |
| 连接建立/关闭 | 是（事件） | `event=connect/disconnect`，含连接 id、拓扑、传输、TLS 是否开启 |
| 授权被拒 | 是 | `event=command_denied, deny_reason=role|grant|protection|risk|session` |
| 敏感值临时显示 | 是 | `event=reveal_sensitive`，记录 key 名摘要、角色、剩余秒数 |
| 未脱敏导出 | 是 | `event=export_unmasked`，记录导出范围、行数、理由 |

所有记录都带 `actor`（账号）、`session_id`、`client_version`、`seq/prev_hash/record_hash`；命令结果以追加事件 `event=command_result` 记录，不修改原记录。

审计表结构（含哈希链 DDL）、哈希链算法、完整性校验与断链处理、保留/归档/导出策略见 [08 §7](./08-安全与风险清单.md)；阈值参数见 [02 附件 A.4/A.8](./02-架构与技术选型.md)。

## 9. 验收要点

| 编号 | 用例 | 通过标准 |
| --- | --- | --- |
| V1 | 只读连接输入 `SET k v` | 无网络请求；提示被只读保护拦截；审计有 `deny` |
| V2 | 生产连接输入 `FLUSHALL` | 拒绝且无任何解锁入口；提示"生产环境永久阻断" |
| V3 | 测试连接输入 `DEL k1 ... k100` | 判定 L3；要求输入连接名；错误输入时"确认"按钮不可用 |
| V4 | `GET` 不存在的 key | 状态列"未命中"，值为 `nil`，耗时正常 |
| V5 | 集群 `MGET k1 k2 k3` 跨 3 槽 | 分 3 次执行，合并结果，标注分组说明，无异常 |
| V6 | `MULTI ... EXEC` 跨槽 | 拒绝并提示 hash tag，不发送 |
| V7 | `LRANGE k 0 -1` | 拒绝并提示改用分页或限定区间 |
| V8 | 命令超时后点取消 | 5 秒内恢复可输入状态；审计记录 `timeout/cancelled` |
| V9 | 历史中的 `AUTH` 命令 | 密码显示为 `***`；复制历史不会带出明文 |
| V10 | 输入未闭合引号 | 本地报错并高亮位置，不发送 |
| V11 | `viewer` 登录后输入 `SET k v` | 发送前拒绝；文案提示需要 Operator；审计 `deny_reason=role` |
| V12 | `operator` 在未授权连接上执行 `GET k` | 拒绝；连接列表该行显示"未授权"徽标 |
| V13 | `admin` 在 `env=prod` 连接执行 `FLUSHALL` | 拒绝，无解锁入口；即使手工改库 `allow_l4=1` 也被 DDL 约束拦住 |
| V14 | 审计库设为只读后执行 `SET k v` | 返回 E13；无网络请求；只读命令仍可执行并显示红色横幅 |
| V15 | 历史回放一条 `DEL k`，当前角色已降为 viewer | 回放被拒（重新判定），不复用上次 `allow` |
| V16 | `GET token:abc` 的返回值 | 默认显示遮罩；点"临时显示"后 60 秒回遮罩；审计出现 `reveal_sensitive` |
| V17 | 导出结果为 CSV（含敏感字段） | 默认脱敏；`operator` 无去脱敏入口，`admin` 去脱敏需口令 + 理由 |
